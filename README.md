# ftth_gpon

Simulador didáctico de redes FTTH-GPON, con backend FastAPI y frontend React.

La viabilidad óptica y el alcance se comprueban en vivo en el editor antes de
ejecutar tráfico. Ver [criterios, límites y API de viabilidad](docs/viabilidad-gpon.md).

Los profesores pueden publicar proyectos para que cada alumno copie y edite su
propia red. Ver [publicación y copias de proyectos](docs/proyectos-publicados.md).
